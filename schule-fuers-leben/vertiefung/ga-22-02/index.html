Offizielle Portale ohne falsche Logins

Interaktiv lernen

Zieladresse und Dienst vor einer Anmeldung verifizieren.

Erklärung

Öffne den gewünschten Behördendienst über eine unabhängig gefundene offizielle Adresse. Prüfe die eigentliche Domain, nicht nur einen vertrauten Begriff irgendwo im Link. AGOV weist darauf hin, dass echte Anmeldungen auf die offizielle Authentifizierungsadresse weiterleiten.

Ein QR-Code kann ebenfalls auf eine betrügerische Seite führen. Das Schloss-Symbol allein beweist keine vertrauenswürdige Organisation. Diese Lernplattform baut kein echtes AGOV-Login nach und verlangt keine Zugangsbestätigung. Sie zeigt nur fiktive Nachrichten und erklärt den sicheren Entscheidungsweg.

Beispiel

auth.agov.admin.ch ist eine andere Domain als ein fremder Host, der den Text admin.ch nur im Pfad zeigt. Im Zweifel wird der echte Dienst unabhängig geöffnet.

So gehst du vor

  1. Nachricht nicht unter Zeitdruck ausführen.
  2. Offiziellen Dienst unabhängig finden.
  3. Hostnamen und beabsichtigte Aktion prüfen.
  4. Unklare Anfrage über einen bekannten Kontakt bestätigen.

Opening

Eine Nachricht fordert Dich auf, Dein AGOV-Konto sofort zu aktualisieren. Was prüfst Du?

Do

Kontrolliere, wo Du Dich tatsächlich anmeldest.

Dont

Halte Logo, QR-Code oder Schloss nicht für einen Echtheitsbeweis.
