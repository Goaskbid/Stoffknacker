Gleichungssysteme und quadratische Gleichungen

Interaktiv lernen Lernweg in Schritten

Zwei Bedingungen gleichzeitig, oder eine Bedingung mit x². Beide Typen kommen in der schriftlichen Prüfung fast sicher vor, oft versteckt in einer Textaufgabe.

Worum es geht

Manchmal muss eine Zahl nicht eine, sondern zwei Bedingungen gleichzeitig erfüllen. Und manchmal kommt die Unbekannte im Quadrat vor, dann kann es plötzlich zwei richtige Antworten geben, eine oder gar keine.

Wozu du das brauchst

Textaufgaben mit zwei Unbekannten und quadratische Ansätze aus Flächen-, Wurf- oder Gewinnproblemen sind schriftliche Standardaufgaben.

Was du schon können solltest

Du solltest lineare Gleichungen sicher nach einer Variablen auflösen können.

Der Kern

Ein Gleichungssystem sucht Werte, die alle Bedingungen zugleich erfüllen, eine quadratische Gleichung kann null, eine oder zwei reelle Lösungen haben.

Begriffe

GleichungssystemMehrere Gleichungen, die gleichzeitig gelten müssen.
EliminationVerfahren, das durch Addieren eine Variable verschwinden lässt.
NullformDie Schreibweise ax² + bx + c = 0, Voraussetzung für jede Formel.
DiskriminanteDer Ausdruck b² − 4ac, er zählt die reellen Lösungen.

Ein verbreiteter Irrtum

Viele teilen x² − 5x = 0 durch x. Damit verschwindet die Lösung x = 0 lautlos. Ausklammern bewahrt beide Lösungen.

Lernziele

  • Lineare Gleichungssysteme mit Einsetzen, Gleichsetzen oder Addieren lösen
  • Quadratische Gleichungen faktorisieren oder mit der Lösungsformel lösen
  • Die Anzahl reeller Lösungen über die Diskriminante bestimmen
  • Aus einer Textaufgabe ein System aufstellen

Ein System ist eine Und-Verknüpfung

x + y = 7 allein hat unendlich viele Lösungen: jedes Paar, dessen Summe 7 ist. Erst eine zweite Bedingung macht die Lösung eindeutig.

Geometrisch beschreibt jede lineare Gleichung mit zwei Variablen eine Gerade. Die Lösung des Systems ist der Schnittpunkt. Daraus folgen sofort alle drei möglichen Fälle: ein Schnittpunkt, keiner bei parallelen Geraden, unendlich viele bei identischen Geraden.

Deshalb ist «keine Lösung» bei einem System kein Rechenfehler, sondern ein mögliches, korrektes Ergebnis.

Verfahren wählen statt stur rechnen

Einsetzen lohnt sich, wenn eine Variable schon isoliert ist oder mit einem Schritt isoliert werden kann.

Addieren (Eliminationsverfahren) lohnt sich, wenn die Koeffizienten einer Variablen gleich oder leicht gleich zu machen sind. Du multiplizierst eine Gleichung passend und addierst dann so, dass eine Variable wegfällt.

Gleichsetzen lohnt sich, wenn beide Gleichungen bereits in der Form y = … vorliegen. Die Wahl des Verfahrens spart in der Prüfung mehr Zeit als schnelles Rechnen.

Quadratisch heisst: zuerst auf null bringen

Die Lösungsformel und das Faktorisieren setzen beide die Form ax² + bx + c = 0 voraus. Solange rechts nicht null steht, ist jede Formel wertlos.

Steht die Null, prüfe zuerst, ob du faktorisieren kannst. x² − 9 = 0 wird zu (x − 3)(x + 3) = 0, und ein Produkt ist genau dann null, wenn ein Faktor null ist. Das ist schneller und fehlerärmer als die Formel.

Erst wenn Faktorisieren nicht gelingt, kommt die Lösungsformel. Sie funktioniert immer, kostet aber mehr Schritte und damit mehr Fehlerchancen.

Die Diskriminante liest die Antwort vorab

In der Lösungsformel steht √(b² − 4ac). Dieser Radikand heisst Diskriminante D und entscheidet allein über die Anzahl reeller Lösungen.

D > 0 bedeutet zwei verschiedene Lösungen, weil eine positive Zahl zwei Wurzeln mit Vorzeichen ± hat. D = 0 bedeutet eine doppelte Lösung, weil ±0 nur einen Wert liefert. D < 0 bedeutet keine reelle Lösung, weil keine reelle Zahl quadriert negativ wird.

Graphisch: D entscheidet, ob die Parabel die x-Achse zweimal schneidet, sie berührt oder ganz über bzw. unter ihr liegt.

Modelle und Formeln

Lösungsformel für quadratische Gleichungen

x = (−b ± √(b² − 4ac)) / (2a)

Sie löst jede Gleichung der Form ax² + bx + c = 0 mit a ≠ 0.

Diskriminante

D = b² − 4ac

D sagt vor dem Rechnen, wie viele reelle Lösungen zu erwarten sind.

Eliminationsverfahren

I · m + II · n → eine Variable fällt weg

Zwei Gleichungen werden so skaliert, dass ihre Summe oder Differenz eine Variable eliminiert.

Durchgerechnete Beispiele

Grundlage

Aufgabe: Löse x + y = 9 und x − y = 3.

  1. Addieren beseitigt y: 2x = 12.
  2. x = 6.
  3. In x + y = 9 einsetzen: 6 + y = 9, also y = 3.
  4. Probe in x − y = 3: 6 − 3 = 3. Stimmt.

Ergebnis: (x; y) = (6; 3)

Aufbau

Aufgabe: Löse 2x² − 8x = 0.

  1. Auf null bringen ist bereits erledigt.
  2. Nicht durch x teilen, sonst verliert man eine Lösung. Statt dessen ausklammern: 2x(x − 4) = 0.
  3. Ein Produkt ist null, wenn ein Faktor null ist: 2x = 0 oder x − 4 = 0.
  4. Also x = 0 oder x = 4.

Ergebnis: x = 0 oder x = 4

Prüfungsniveau

Aufgabe: Ein Rechteck hat einen Umfang von 26 cm und eine Fläche von 40 cm². Bestimme die Seitenlängen.

  1. Bedingungen aufstellen: 2(a + b) = 26 und a · b = 40, also a + b = 13.
  2. Aus der ersten Bedingung b = 13 − a.
  3. Einsetzen in die zweite: a(13 − a) = 40, also 13a − a² = 40.
  4. Auf null bringen: a² − 13a + 40 = 0.
  5. D = 169 − 160 = 9, also a = (13 ± 3)/2, somit a = 8 oder a = 5.
  6. Beide Werte sind gültig und beschreiben dasselbe Rechteck: Seiten 8 cm und 5 cm.
  7. Kontrolle: Umfang 2(8 + 5) = 26 cm, Fläche 8 · 5 = 40 cm².

Ergebnis: 8 cm und 5 cm

Typischer Fehler

In der Lösungsformel wird das Vorzeichen von b oder der Nenner 2a falsch gesetzt, häufig wird nur der Wurzelterm durch 2a geteilt.

Merkhilfe

System: eine Variable beseitigen. Quadratisch: zuerst auf null, dann faktorisieren, sonst Formel.

Das Wichtigste

  • Jede lineare Gleichung mit zwei Variablen ist eine Gerade, die Systemlösung ihr Schnittpunkt.
  • Vor jeder quadratischen Methode die Form ax² + bx + c = 0 herstellen.
  • Nie durch x teilen, um x² zu entfernen: das löscht die Lösung x = 0.
  • D = b² − 4ac entscheidet über zwei, eine oder keine reelle Lösung.
  • Bei Systemen gilt die Probe in beiden Ausgangsgleichungen, nicht nur in einer.
