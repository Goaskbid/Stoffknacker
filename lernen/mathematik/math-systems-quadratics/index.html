Gleichungssysteme und quadratische Gleichungen

Interaktiv lernen Lernweg in Schritten

Zwei Bedingungen gleichzeitig, oder eine Bedingung mit x². Beide Typen kommen in der schriftlichen Prüfung fast sicher vor, oft versteckt in einer Textaufgabe.

Worum es geht

Manchmal muss eine Zahl nicht eine, sondern zwei Bedingungen gleichzeitig erfüllen. Und manchmal kommt die Unbekannte im Quadrat vor, dann kann es plötzlich zwei richtige Antworten geben, eine oder gar keine.

Wozu du das brauchst

Textaufgaben mit zwei Unbekannten und quadratische Ansätze aus Flächen-, Wurf- oder Gewinnproblemen sind schriftliche Standardaufgaben.

Was du schon können solltest

Du solltest lineare Gleichungen sicher nach einer Variablen auflösen können.

Der Kern

Ein Gleichungssystem sucht Werte, die alle Bedingungen zugleich erfüllen, eine quadratische Gleichung kann null, eine oder zwei reelle Lösungen haben.

Begriffe

GleichungssystemMehrere Gleichungen, die gleichzeitig gelten müssen.
EliminationVerfahren, das durch Addieren eine Variable verschwinden lässt.
NullformDie Schreibweise ax² + bx + c = 0, Voraussetzung für jede Formel.
DiskriminanteDer Ausdruck b² − 4ac, er zählt die reellen Lösungen.

Ein verbreiteter Irrtum

Viele teilen x² − 5x = 0 durch x. Damit verschwindet die Lösung x = 0 lautlos. Ausklammern bewahrt beide Lösungen.

Lernziele

  • Lineare Gleichungssysteme mit Einsetzen, Gleichsetzen oder Addieren lösen
  • Quadratische Gleichungen faktorisieren oder mit der Lösungsformel lösen
  • Die Anzahl reeller Lösungen über die Diskriminante bestimmen
  • Aus einer Textaufgabe ein System aufstellen

Ein System ist eine Und-Verknüpfung

x + y = 7 allein hat unendlich viele Lösungen: jedes Paar, dessen Summe 7 ist. Erst eine zweite Bedingung macht die Lösung eindeutig.

Geometrisch beschreibt jede lineare Gleichung mit zwei Variablen eine Gerade. Die Lösung des Systems ist der Schnittpunkt. Daraus folgen sofort alle drei möglichen Fälle: ein Schnittpunkt, keiner bei parallelen Geraden, unendlich viele bei identischen Geraden.

Deshalb ist «keine Lösung» bei einem System kein Rechenfehler, sondern ein mögliches, korrektes Ergebnis.

0

0 = 5 ist eine falsche Aussage, unabhängig von x und y. Die beiden Geraden sind parallel und schneiden sich nie, das System hat keine Lösung.

Verfahren wählen statt stur rechnen

Einsetzen lohnt sich, wenn eine Variable schon isoliert ist oder mit einem Schritt isoliert werden kann.

Addieren (Eliminationsverfahren) lohnt sich, wenn die Koeffizienten einer Variablen gleich oder leicht gleich zu machen sind. Du multiplizierst eine Gleichung passend und addierst dann so, dass eine Variable wegfällt.

Gleichsetzen lohnt sich, wenn beide Gleichungen bereits in der Form y = … vorliegen. Die Wahl des Verfahrens spart in der Prüfung mehr Zeit als schnelles Rechnen.

Quadratisch heisst: zuerst auf null bringen

Die Lösungsformel und das Faktorisieren setzen beide die Form ax² + bx + c = 0 voraus. Solange rechts nicht null steht, ist jede Formel wertlos.

Steht die Null, prüfe zuerst, ob du faktorisieren kannst. x² − 9 = 0 wird zu (x − 3)(x + 3) = 0, und ein Produkt ist genau dann null, wenn ein Faktor null ist. Das ist schneller und fehlerärmer als die Formel.

Erst wenn Faktorisieren nicht gelingt, kommt die Lösungsformel. Sie funktioniert immer, kostet aber mehr Schritte und damit mehr Fehlerchancen.

Die Diskriminante liest die Antwort vorab

In der Lösungsformel steht √(b² − 4ac). Dieser Radikand heisst Diskriminante D und entscheidet allein über die Anzahl reeller Lösungen.

D > 0 bedeutet zwei verschiedene Lösungen, weil eine positive Zahl zwei Wurzeln mit Vorzeichen ± hat. D = 0 bedeutet eine doppelte Lösung, weil ±0 nur einen Wert liefert. D < 0 bedeutet keine reelle Lösung, weil keine reelle Zahl quadriert negativ wird.

Graphisch: D entscheidet, ob die Parabel die x-Achse zweimal schneidet, sie berührt oder ganz über bzw. unter ihr liegt.

numeric

Berechne die Diskriminante von 2x² + 4x + 5 = 0.

-24

0

D = b² − 4ac = 4² − 4 · 2 · 5 = 16 − 40 = −24. Weil D negativ ist, gibt es keine reelle Lösung.

Modelle und Formeln

Lösungsformel für quadratische Gleichungen

x = (−b ± √(b² − 4ac)) / (2a)

Sie löst jede Gleichung der Form ax² + bx + c = 0 mit a ≠ 0.

aKoeffizient von x², a ≠ 0
bKoeffizient von x, mit Vorzeichen
cKonstante, mit Vorzeichen
D = b² − 4acDiskriminante

Die Formel ist keine Magie, sondern eine einmal durchgeführte quadratische Ergänzung. Wer die Herleitung einmal nachvollzieht, kann sie im Notfall rekonstruieren und verwechselt die Vorzeichen nicht mehr.

Ausgangsformax² + bx + c = 0Ohne die Null rechts gilt keiner der folgenden Schritte.
Durch a normierenx² + (b/a)x + c/a = 0Division durch a ≠ 0 macht den Koeffizienten vor x² zu eins. Nur so lässt sich ein vollständiges Quadrat bilden.
Konstante nach rechtsx² + (b/a)x = −c/aLinks soll nur das stehen, was zum Quadrat ergänzt wird.
Quadratisch ergänzenx² + (b/a)x + (b/2a)² = −c/a + (b/2a)²Die halbe x-Koeffizient, quadriert, ist genau der fehlende Term für ein vollständiges Quadrat. Er muss auf beiden Seiten addiert werden.
Links als Quadrat schreiben(x + b/2a)² = (b² − 4ac) / (4a²)Links greift die binomische Formel. Rechts wird auf den gemeinsamen Nenner 4a² gebracht, dabei entsteht der Ausdruck b² − 4ac.
Wurzel ziehen, beide Vorzeichenx + b/2a = ± √(b² − 4ac) / (2a)Aus u² = v folgt u = +√v oder u = −√v. Das ± ist der Grund, warum es zwei Lösungen geben kann.
x isolierenx = (−b ± √(b² − 4ac)) / (2a)Subtrahieren von b/2a und Zusammenfassen über den gemeinsamen Nenner 2a liefert die bekannte Form.

Löse x² − 5x + 6 = 0.

  • Koeffizienten ablesen: a = 1, b = −5, c = 6.
  • D = (−5)² − 4 · 1 · 6 = 25 − 24 = 1.
  • √D = 1 und −b = +5, also x = (5 ± 1) / 2.
  • x₁ = 6/2 = 3 und x₂ = 4/2 = 2.
  • Probe: 3 · 2 = 6 = c und 3 + 2 = 5 = −b. Passt.

x = 2 oder x = 3

b wird mit seinem Vorzeichen eingesetzt. Bei b = −5 ist −b = +5, und b² = +25, nicht −25.

Koeffizient von x²

a

Bestimmt die Öffnung und Breite der Parabel.

Bei a > 0 öffnet sie nach oben, bei a < 0 nach unten. Grosses |a| macht sie schmal.

Koeffizient von x

b

Verschiebt die Parabel seitlich.

Der Scheitel liegt bei −b/(2a). Vorzeichen unbedingt mitnehmen.

konstantes Glied

c

Der y-Achsenabschnitt der Parabel.

c verschiebt die ganze Parabel nach oben oder unten und kann so die Zahl der Nullstellen ändern.

Diskriminante

D = b² − 4ac

Der Ausdruck unter der Wurzel.

D > 0 zwei Lösungen, D = 0 eine doppelte, D < 0 keine reelle.

Alle Terme sind reine Zahlen. Kontrolle über den Satz von Vieta: x₁ · x₂ = c/a und x₁ + x₂ = −b/a.

Aus ax² + bx + c = 0 wird nach Division durch a und quadratischer Ergänzung (x + b/2a)² = (b² − 4ac)/(4a²).

Diskriminante

D = b² − 4ac

D sagt vor dem Rechnen, wie viele reelle Lösungen zu erwarten sind.

D > 0zwei verschiedene reelle Lösungen
D = 0eine doppelte reelle Lösung
D < 0keine reelle Lösung

D ist genau der Ausdruck unter der Wurzel der Lösungsformel. Die Anzahl reeller Wurzeln einer Zahl bestimmt damit direkt die Anzahl der Lösungen.

Herkunft benennenx = (−b ± √D) / (2a)D taucht nur an einer Stelle auf, nämlich unter der Wurzel.
Fall D > 0√D ist eine positive ZahlMit ± entstehen zwei verschiedene Werte für x, also zwei Schnittpunkte mit der x-Achse.
Fall D = 0√0 = 0, also x = −b / (2a)Plus und minus null sind derselbe Wert. Es bleibt eine Lösung, die Parabel berührt die x-Achse.
Fall D < 0√(negativ) existiert reell nichtKein reelles x erfüllt die Gleichung. Die Parabel liegt vollständig über oder unter der x-Achse.

Wie viele reelle Lösungen hat 3x² − 6x + 3 = 0?

  • a = 3, b = −6, c = 3.
  • D = 36 − 4 · 3 · 3 = 36 − 36 = 0.
  • D = 0 bedeutet eine doppelte Lösung.
  • x = −(−6) / (2 · 3) = 1.

Eine doppelte Lösung, x = 1

D beantwortet nur die Frage nach der Anzahl. Bei D ≥ 0 musst du die Lösungen anschliessend trotzdem berechnen.

Diskriminante

D

Der Wert unter der Wurzel der Lösungsformel.

D > 0 zwei Lösungen, D = 0 eine doppelte, D < 0 keine reelle.

Quadrat des x-Koeffizienten

Immer positiv, unabhängig vom Vorzeichen von b.

Bei b = −5 ist b² = +25, nicht −25.

Produktterm

Verbindet Öffnung und y-Achsenabschnitt.

Haben a und c gleiche Vorzeichen, wird D kleiner und reelle Lösungen seltener.

Alle Terme reine Zahlen. Kontrolle über Vieta: x₁·x₂ = c/a.

D = b² − 4ac. Bei D ≥ 0 anschliessend x = (−b ± √D)/(2a).

Eliminationsverfahren

I · m + II · n → eine Variable fällt weg

Zwei Gleichungen werden so skaliert, dass ihre Summe oder Differenz eine Variable eliminiert.

I, IIdie beiden Gleichungen
m, ngewählte Faktoren

Sind zwei Gleichungen beide wahr, ist auch jede Linearkombination von ihnen wahr. Diese Freiheit nutzt man, um eine Variable gezielt zu tilgen.

Ziel festlegenKoeffizienten einer Variablen gleich gross machenNur bei gleichem Betrag hebt sich der Term beim Addieren oder Subtrahieren auf.
Passend multiplizierenI · 3 und II · 2, wenn die Koeffizienten 2 und 3 sindMultiplizieren einer ganzen Gleichung mit einer Zahl ≠ 0 ist eine Äquivalenzumformung, verändert also die Lösungsmenge nicht.
Addieren oder subtrahieren6y − 6y = 0Die Variable verschwindet, es bleibt eine Gleichung mit nur einer Unbekannten.
Rückeinsetzengefundenen Wert in I oder II einsetzenDamit ergibt sich die zweite Variable.
Beide Gleichungen prüfenProbe in I und IIEin Wertepaar löst das System nur, wenn es alle Bedingungen erfüllt, nicht nur eine.

Löse 3x + 2y = 16 und 5x − 2y = 8.

  • Die y-Koeffizienten sind +2 und −2, also direkt addieren.
  • Addition: 8x = 24, somit x = 3.
  • In die erste Gleichung: 9 + 2y = 16, also 2y = 7 und y = 3,5.
  • Probe in der zweiten Gleichung: 15 − 7 = 8. Stimmt.

(x; y) = (3; 3,5)

Wird nur eine Gleichung multipliziert, muss die Multiplikation auch die rechte Seite treffen. Ein häufiger Punkteverlust.

Multiplikatoren

m, n

Faktoren, mit denen die Gleichungen skaliert werden.

So gewählt, dass die Koeffizienten einer Variablen gleich gross werden.

die beiden Gleichungen

I, II

Beide müssen gleichzeitig gelten.

Jede Linearkombination wahrer Gleichungen ist wieder wahr. Darauf beruht das Verfahren.

Keine Einheiten im Mathematikteil. In Sachaufgaben müssen alle Gleichungen dieselbe Einheit verwenden.

I·m ± II·n so, dass eine Variable wegfällt. Danach rückeinsetzen und in beiden Gleichungen prüfen.

Durchgerechnete Beispiele

Grundlage

Aufgabe: Löse x + y = 9 und x − y = 3.

  1. Addieren beseitigt y: 2x = 12.
  2. x = 6.
  3. In x + y = 9 einsetzen: 6 + y = 9, also y = 3.
  4. Probe in x − y = 3: 6 − 3 = 3. Stimmt.

Ergebnis: (x; y) = (6; 3)

Aufbau

Aufgabe: Löse 2x² − 8x = 0.

  1. Auf null bringen ist bereits erledigt.
  2. Nicht durch x teilen, sonst verliert man eine Lösung. Statt dessen ausklammern: 2x(x − 4) = 0.
  3. Ein Produkt ist null, wenn ein Faktor null ist: 2x = 0 oder x − 4 = 0.
  4. Also x = 0 oder x = 4.

Ergebnis: x = 0 oder x = 4

Prüfungsniveau

Aufgabe: Ein Rechteck hat einen Umfang von 26 cm und eine Fläche von 40 cm². Bestimme die Seitenlängen.

  1. Bedingungen aufstellen: 2(a + b) = 26 und a · b = 40, also a + b = 13.
  2. Aus der ersten Bedingung b = 13 − a.
  3. Einsetzen in die zweite: a(13 − a) = 40, also 13a − a² = 40.
  4. Auf null bringen: a² − 13a + 40 = 0.
  5. D = 169 − 160 = 9, also a = (13 ± 3)/2, somit a = 8 oder a = 5.
  6. Beide Werte sind gültig und beschreiben dasselbe Rechteck: Seiten 8 cm und 5 cm.
  7. Kontrolle: Umfang 2(8 + 5) = 26 cm, Fläche 8 · 5 = 40 cm².

Ergebnis: 8 cm und 5 cm

Typischer Fehler

In der Lösungsformel wird das Vorzeichen von b oder der Nenner 2a falsch gesetzt, häufig wird nur der Wurzelterm durch 2a geteilt.

Merkhilfe

System: eine Variable beseitigen. Quadratisch: zuerst auf null, dann faktorisieren, sonst Formel.

Das Wichtigste

  • Jede lineare Gleichung mit zwei Variablen ist eine Gerade, die Systemlösung ihr Schnittpunkt.
  • Vor jeder quadratischen Methode die Form ax² + bx + c = 0 herstellen.
  • Nie durch x teilen, um x² zu entfernen: das löscht die Lösung x = 0.
  • D = b² − 4ac entscheidet über zwei, eine oder keine reelle Lösung.
  • Bei Systemen gilt die Probe in beiden Ausgangsgleichungen, nicht nur in einer.
