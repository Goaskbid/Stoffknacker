Programmieren: Variablen, Bedingungen und Schleifen

Ein Programm ist wie ein sehr genauer Befehlszettel. Mit drei Werkzeugen kommst du weit: Variablen (Schubladen für Werte), Bedingungen (wenn … dann) und Schleifen (wiederhole …).

Worum es geht

Ein Programm ist wie ein sehr genauer Befehlszettel.

Der Kern

Merke: Variablen merken sich Werte, Bedingungen entscheiden, Schleifen wiederholen.

Wozu du das brauchst

Wozu: Du kannst ein kurzes Programm lesen, voraussagen, was es ausgibt, und Fehler finden.

Grundlegendes Lesen, strukturierte Notizen und Bereitschaft, Entscheidungen zu begründen.

Programme schreiben

Beim Nachverfolgen notiert man nach jeder Anweisung die Werte der Variablen. So sieht man, was das Programm tatsächlich tut.

Arbeite mit einem kleinen Beispiel, formuliere den Ablauf eindeutig und prüfe ihn mit Gegenfällen.

Testfälle

Ein Testfall legt Eingabe und erwartete Ausgabe fest. Gute Tests prüfen den Normalfall, Grenzfälle wie 0 oder eine leere Liste und ungültige Eingaben.

Ein Beispiel: Für eine Funktion, die den Durchschnitt berechnet, testet man eine normale Liste, eine leere Liste und negative Zahlen. So zeigen sich Fehler, bevor andere das Programm nutzen.

Fehlersuche

Man grenzt einen Fehler ein, indem man Zwischenwerte ausgibt oder Teile einzeln testet. Syntaxfehler meldet der Rechner, Logikfehler nicht.

Logische Fehler sind schwieriger, weil das Programm läuft, aber ein falsches Ergebnis liefert. Kleine, gezielte Tests helfen, sie Schritt für Schritt einzugrenzen.

Anwendung, Transfer

Zum Abschluss überträgst du die drei Kernbereiche auf eine neue Situation. Eine gute Lösung nennt Ausgangslage, Vorgehen, Ergebnis und Kontrolle.

Entwirf eine kleine digitale Lösung und begründe Datenmodell, Ablauf, Tests und Schutzmassnahmen. Die Begründung muss zeigen, warum das Vorgehen zur Frage passt.

Aufgabe: Entwirf eine kleine digitale Lösung und begründe Datenmodell, Ablauf, Tests und Schutzmassnahmen.

Typischer Fehler

Eine plausible Ausgabe beweist noch nicht, dass ein Algorithmus für alle Fälle korrekt ist.
