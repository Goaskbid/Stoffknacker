Listen

Eine Liste speichert Werte in fester Reihenfolge mit Index. Eine Zuordnung, auch Wörterbuch genannt, verknüpft Schlüssel mit Werten.

Arbeite mit einem kleinen Beispiel, formuliere den Ablauf eindeutig und prüfe ihn mit Gegenfällen.

Funktionen

Eine Funktion bündelt Anweisungen unter einem Namen, nimmt Parameter entgegen und gibt ein Ergebnis zurück. Sie macht Code wiederverwendbar und einzeln testbar.

Ein Beispiel: Eine Funktion Flaeche(Breite, Hoehe) gibt das Produkt der beiden Werte zurück. So lässt sich dieselbe Berechnung an vielen Stellen verwenden.

Abstraktion

Abstraktion blendet Details aus, die für die aktuelle Aufgabe unwichtig sind. Wer eine Funktion aufruft, muss wissen, was sie tut, nicht wie.

Ein Vergleich ist die Fernbedienung: Man drückt eine Taste, ohne die Elektronik dahinter zu kennen. Genauso erleichtert Abstraktion die Arbeit an grossen Programmen.

Anwendung, Transfer

Zum Abschluss überträgst du die drei Kernbereiche auf eine neue Situation. Eine gute Lösung nennt Ausgangslage, Vorgehen, Ergebnis und Kontrolle.

Entwirf eine kleine digitale Lösung und begründe Datenmodell, Ablauf, Tests und Schutzmassnahmen. Die Begründung muss zeigen, warum das Vorgehen zur Frage passt.

Durchgerechnete Beispiele

Anwendung

Aufgabe: Entwirf eine kleine digitale Lösung und begründe Datenmodell, Ablauf, Tests und Schutzmassnahmen.

  1. Klären: Listen und Zuordnungen
  2. Anwenden: Funktionen
  3. Einbeziehen: Abstraktion
  4. Kontrollieren: Ergebnis und Begründung

Ergebnis: Eine nachvollziehbare, kontrollierte Lösung.

Transfer

Aufgabe: Übertrage das Kernprinzip aus «Datenstrukturen und Modularisierung» auf eine neue Situation und nenne eine Grenze der Übertragung.

  1. Situation strukturieren
  2. Gemeinsame Merkmale bestimmen
  3. Unterschiede markieren
  4. Schlussfolgerung begrenzen

Ergebnis: Ein begründeter Transfer mit klarer Grenze.
