Worum es geht

Ein Programm soll aus [-3, -8, -1] den grössten Wert bestimmen. Wer den bisherigen Höchstwert mit null startet, erhält null, obwohl dieser Wert in der Liste gar nicht vorkommt. Der Fehler liegt nicht in einer komplizierten Formel, sondern in einer unbegründeten Startannahme.

Der Kern

Merke: Ein Algorithmus ist eine genaue Anleitung, die bei jedem Durchlauf zum richtigen Ergebnis führt.

Wozu: Du kannst Lösungswege aufschreiben, die andere (und Computer) Schritt für Schritt nachvollziehen.

Zerlegung

Ein grosses Problem wird in kleine Teilprobleme zerlegt, die sich einzeln lösen und testen lassen.

Arbeite mit einem kleinen Beispiel, formuliere den Ablauf eindeutig und prüfe ihn mit Gegenfällen.

Pseudocode

Eine knappe, programmnahe Beschreibung des Ablaufs, unabhängig von einer Programmiersprache. Sie zeigt Schritte, Bedingungen und Wiederholungen.

Pseudocode beschreibt die Verarbeitung ohne die Syntax einer bestimmten Programmiersprache. Eine endende Warteschleife lautet etwa: Solange die Warteschlange nicht leer ist, entferne ihr erstes Element und prüfe dieses Element. Das Entfernen ist entscheidend: Ohne Zustandsänderung könnte dieselbe erste Position immer wieder gelesen werden.

Korrektheit

Ein Algorithmus ist korrekt, wenn er für jede zulässige Eingabe das richtige Ergebnis liefert. Der Aufwand beschreibt, wie Laufzeit oder Speicher mit der Eingabegrösse wachsen.

Genauer betrachtet

Ein Algorithmus braucht einen Eingabevertrag. Hier ist die Eingabe eine nicht leere Liste vergleichbarer Zahlen. Für eine leere Liste legen wir ausdrücklich fest, dass ein Fehler gemeldet wird; wir erfinden kein Maximum.

Die Schleifeninvariante beschreibt, was nach jedem Schritt bereits stimmt: best ist das Maximum der bislang bearbeiteten Elemente. Initialisierst du best mit dem ersten Element, gilt das bereits vor dem ersten Vergleich der restlichen Elemente.

Mit jedem Durchlauf kommt genau ein weiterer Wert hinzu. Ist er grösser, ersetzt er best; sonst bleibt best bestehen. Weil die Liste endlich ist und jedes Element nur einmal besucht wird, endet dieser Algorithmus.

Durchgerechnete Beispiele

Algorithmen und Problemlösen

Aufgabe: Eingabe [-3, -8, -1]. Gesucht sind Maximum, Vergleichsfolge und ein Verhalten für die Leerliste. Es wird nichts sortiert und die Eingabeliste bleibt unverändert.

  1. Initialisierung mit dem ersten Element: best = -3. Von den bisher gesehenen Elementen, nur -3, ist -3 tatsächlich das Maximum.
  2. Nächster Wert -8: -8 ist nicht grösser als -3, also bleibt best = -3. Die Invariante gilt jetzt für [-3, -8].
  3. Nächster Wert -1: -1 ist grösser als -3, also wird best = -1. Danach sind alle drei Werte verarbeitet.
  4. Die Variante best = 0 würde keinen der negativen Werte übernehmen und fälschlich 0 liefern. Bei [0, -2] wäre null dagegen zufällig richtig; gerade deshalb braucht der Test auch ausschliesslich negative Werte.

Ergebnis: Das Maximum ist -1. Für n Elemente benötigt die gezeigte Variante n - 1 Wertvergleiche, sofern n mindestens eins ist. Kontrolle: Teste eine Einzelliste, gleiche Werte, ausschliesslich negative Werte und die Leerliste. Der Code prüft ausserdem, dass der Ursprungswert der Eingabe erhalten bleibt.

Grenzen: Die Aussage n - 1 zählt nur die gezeigten Wertvergleiche, nicht jede Pythonoperation oder den Speicherzugriff.

Python-Beispiel zum Ausprobieren:

def maximum(values):
    if not values:
        raise ValueError('empty input')
    best = values[0]
    for value in values[1:]:
        if value > best:
            best = value
    return best
assert maximum([-3, -8, -1]) == -1
assert maximum([0, -2]) == 0
assert maximum([4, 4, 4]) == 4

Verständnis prüfen

Offene Fragen mit Musterantwort aus der KI-Prüfung. Es gibt keine automatische Bewertung.

Warum ist der erste Wert ein besserer Start als null?

Er stammt garantiert aus der nicht leeren Eingabe und macht die Invariante ohne Vorzeichenannahme wahr.

Was liefert die Funktion bei [4, 4, 4]?

4. Gleiche Werte müssen den gespeicherten Wert nicht ersetzen, damit das Maximum korrekt bleibt.

Warum nicht null für eine leere Liste zurückgeben?

Weil null ein inhaltlicher Zahlenwert wäre. Der festgelegte Fehler macht sichtbar, dass das Maximum ohne Eingabeelement nicht definiert wurde.

Typischer Fehler

Eine plausible Ausgabe beweist noch nicht, dass ein Algorithmus für alle Fälle korrekt ist.
