Hardware-

Ein Rechner arbeitet in Schichten: Hardware, Betriebssystem, Anwendungen. Jede Ebene nutzt die Dienste der darunterliegenden.

Arbeite mit einem kleinen Beispiel, formuliere den Ablauf eindeutig und prüfe ihn mit Gegenfällen.

Internetprotokolle

IP adressiert und leitet Datenpakete weiter, TCP sorgt für vollständige und geordnete Übertragung, HTTP für den Abruf von Webseiten.

HTTP regelt, wie Browser und Webserver Seiten austauschen, HTTPS verschlüsselt diese Verbindung zusätzlich. Die Protokolle bauen wie Schichten aufeinander auf.

Client

Der Client stellt eine Anfrage, der Server beantwortet sie. Ein Browser ist ein Client, der Rechner mit der Website ein Server.

Beim Aufruf einer Webseite schickt der Browser eine Anfrage, der Server liefert die Seite zurück. Viele Clients können gleichzeitig denselben Server nutzen.
