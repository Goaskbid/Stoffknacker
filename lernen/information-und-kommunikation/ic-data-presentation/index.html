Diagrammwahl

Säulen vergleichen Kategorien, Linien zeigen Entwicklungen über die Zeit, Streudiagramme den Zusammenhang zweier Grössen.

Recherchiere, ordne, gestalte, teste und dokumentiere jede Produktionsentscheidung.

Kreisdiagramme eignen sich nur für Anteile an einem Ganzen mit wenigen Teilen. Wer das passende Diagramm wählt, macht die Aussage auf einen Blick sichtbar.

Darstellungsintegrität

Eine Grafik darf nicht täuschen: Säulenachsen beginnen bei null, Massstäbe bleiben gleich, Quellen werden genannt.

Eine abgeschnittene Achse kann einen kleinen Unterschied riesig erscheinen lassen. Prüfe deshalb jede Grafik darauf, ob sie die Daten fair zeigt.

Erzählstruktur

Eine Präsentation führt von der Frage über die wichtigste Beobachtung zur Schlussfolgerung.

Jede Folie oder Grafik sollte eine Aussage tragen, die im Titel steht. So können Zuhörende der Argumentation folgen, auch wenn sie nicht jedes Detail sehen.

Anwendung, Transfer

Zum Abschluss überträgst du die drei Kernbereiche auf eine neue Situation. Eine gute Lösung nennt Ausgangslage, Vorgehen, Ergebnis und Kontrolle.

Erstelle ein Informationsprodukt für eine konkrete Zielgruppe und prüfe Verständlichkeit, Quellen und Gestaltung. Die Begründung muss zeigen, warum das Vorgehen zur Frage passt.

Transfer

Ergebnis: Ein begründeter Transfer mit klarer Grenze.
