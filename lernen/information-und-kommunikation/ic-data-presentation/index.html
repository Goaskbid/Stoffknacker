Erzählstruktur

Eine Präsentation führt von der Frage über die wichtigste Beobachtung zur Schlussfolgerung.

Jede Folie oder Grafik sollte eine Aussage tragen, die im Titel steht. So können Zuhörende der Argumentation folgen, auch wenn sie nicht jedes Detail sehen.

Durchgerechnete Beispiele

Eine halbierte Zahl kann eine unveränderte Quote verdecken

Aufgabe: Fiktive Monate: Januar 20 fehlerhafte Formulare unter 1’000 Vorgängen; Februar 10 unter 500. Eine Werbezeile behauptet «Qualität um 50% verbessert».

  1. Absolute Fehlerzahl: 20 auf 10, also −50%. Das ist rechnerisch richtig.
  2. Fehlerquoten: 20/1’000 = 2% und 10/500 = 2%. Die Quote bleibt gleich.
  3. Schreibe: «Bei halbiertem Vorgangsvolumen halbierte sich die Fehlerzahl; der Anteil fehlerhafter Formulare blieb bei 2%.» Zeige die beiden Grundzahlen, nicht nur die abgeleitete Quote.

Ergebnis: Die Daten stützen keine Verbesserung der gemessenen Fehlerquote. Eine korrekte Teilzahl kann dennoch einen falschen Gesamteindruck erzeugen.

Grenzen: Weitere Qualitätsmerkmale wie Fehlerschwere und Nachbearbeitungszeit fehlen. Auch gleiche Quoten bedeuten nicht automatisch gleiche Gesamtqualität.

Verständnis prüfen

Offene Fragen mit Musterantwort. Es gibt keine automatische Bewertung.

Warum ist die Werbezeile problematisch?

Sie macht aus der halben absoluten Fehlerzahl eine Qualitätsverbesserung, obwohl die Bezugsmenge ebenfalls halbiert wurde.

Wie verändert sich die Quote bei 10 Fehlern unter 1’000 Vorgängen?

Auf 1%, also minus 1 Prozentpunkt beziehungsweise eine relative Halbierung gegenüber 2%.

Typischer Fehler

Ein attraktives Layout kann schwache Quellen oder eine unklare Botschaft nicht ersetzen.
